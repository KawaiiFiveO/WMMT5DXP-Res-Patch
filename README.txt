5DX+ Multiversion Resolution Patch

Instructions:

1. Place patch.exe in game directory (containing wmn5r.exe)

2. Run patch.exe and type in name of the game executable (wmn5r.exe)

3. After patching, move the original wmn5r.exe file to another directory as a backup

3. Rename the patched file (example: wmn5r_1920x1080.exe) to wmn5r.exe and select it in TP
